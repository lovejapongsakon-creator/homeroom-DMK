    บันทึกแล้วยังไม่บันทึกปิดห้อง

    กดแล้วแอปไลน์จะเปิดขึ้น เลือกกลุ่มครู แล้วกดส่ง · ใช้ได้ทั้งกลุ่มปกติและโอเพนแชท ไม่ต้องตั้งค่า ไม่เสียโควตา

    ผู้ช่วยเขียนอัตโนมัติ (AI · Google Gemini)

    ใช้เขียนสาระสำคัญโฮมรูมและสรุปรายงานเป็นภาษาราชการ · ถ้า AI ใช้ไม่ได้ ระบบจะใช้ข้อความสำเร็จรูปแทนโดยอัตโนมัติ · คีย์ถูกเก็บในเซิร์ฟเวอร์ ไม่แสดงในหน้าเว็บ

    ยังไม่ได้ตั้งค่า
    ส่งอัตโนมัติผ่านบัญชี LINE ของโรงเรียน (ขั้นสูง · ไม่จำเป็น)
    LINE ส่งสรุปเข้ากลุ่มไลน์อัตโนมัติผ่าน LINE Official Account ของโรงเรียน ยังไม่เปิดใช้งาน
    วิธีตั้งค่าครั้งแรก (5 ขั้น)
    1. สร้างบัญชีที่ manager.line.biz แล้วเปิด Messaging API (ตั้งค่า > Messaging API)
    2. ที่ developers.line.biz แท็บ Messaging API กด Issue คัดลอก Channel access token มาวางช่องด้านล่าง แล้วกด “บันทึก”
    3. ในแท็บเดียวกัน ตรง Webhook URL วางลิงก์นี้ เปิด Use webhook
    4. ที่ manager.line.biz > ตั้งค่าบัญชี เปิด “อนุญาตให้เข้าร่วมแชทกลุ่ม” และปิดข้อความตอบกลับอัตโนมัติ/ข้อความทักทาย
    5. เชิญบัญชีโรงเรียนเข้า กลุ่มไลน์ครู แล้วพิมพ์ในกลุ่มว่า สรุปโฮมรูม 1 ครั้ง → กด “รีเฟรช” ด้านล่าง กลุ่มจะขึ้นให้เลือก
    ผู้ดูแลต้องเพิ่มบัญชีโรงเรียนเป็นเพื่อน แล้วพิมพ์ “สรุปโฮมรูม” 1 ครั้ง ชื่อจึงจะขึ้นให้เลือก
    กรอก ID ปลายทางเอง

    ครูพิมพ์ สรุปโฮมรูม ในกลุ่มเมื่อไรก็ได้ ระบบตอบกลับทันที (ข้อความตอบกลับไม่นับโควตา)
